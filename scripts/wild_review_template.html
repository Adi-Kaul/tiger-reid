How to use

Groups are Claude's proposals, not truth. "event" groups = same camera, same day, same flank. "circles" / "visual" = Claude's guesses from looking at the crops. Singletons have no proposal yet.

For each image, set the tiger ID (type any name; images with the same ID are the same tiger) and a confidence: sure, probable, unsure, or skip (unusable). Only compare same-side images: left and right flanks have different stripes. To link a left and right flank of the same tiger (e.g. a frontal shot showing both), give them the same ID and note it.

Click images to add them to the compare tray at the bottom (side by side, large). Work autosaves in this browser; press Export when done and send me the file.
